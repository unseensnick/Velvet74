# my-soffle

A personal Sofle-style split ergonomic keyboard: [Ergogen](https://github.com/ergogen/ergogen) layout
configs for the key positions and board outline, plus a KiCad 8 project for the onboard RP2040
controller.

## What is in here

| Path | What it is |
| --- | --- |
| `soffle-choc-version.yaml` | Choc-spacing layout, v1: points only |
| `soffle-choc-version-v2.yaml` | v1 plus matrix net assignments |
| `soffle-choc-version-v3.yaml` | Current version: adds board outline and full PCB footprint definitions |
| `soffle-mx-version.yaml` | Same hand layout at MX spacing (19.05 mm) |
| `sofle-choc-pro.kicad_sch` | RP2040 controller schematic |
| `sofle-choc-pro.kicad_pcb` | Board layout (empty, not started yet) |
| `sofle-choc-pro-backups/` | KiCad's own auto-generated project snapshots |

## Layout

Each half is 37 keys:

- **Matrix**: 6 columns (`pinky`, `pinky2`, `ring`, `middle`, `index`, `outer`) by 5 rows
  (`fn`, `number`, `top`, `home`, `bottom`), with column stagger of 0 / 0 / 4.0 / 2.5 / -2.5 / -2.5 mm.
- **Thumb cluster**: 5 keys across five separately anchored zones, the outermost rotated -18 degrees
  and 26.5 mm tall (a 1.5U thumb key).
- **Extra**: 2 points above the outer column that carry the rotary encoders.

The right half is generated by mirroring around `matrix_outer_home` at 85 mm (90 mm for the MX
version). Choc keys are 17.5 x 16.5 mm on `cx`/`cy` spacing; the MX version uses 19.05 mm padding
and spread.

### Version history

`v1` defines the point geometry only. `v2` adds `column_net` / `row_net` on every zone, wiring the
matrix to RP2040 GPIOs (columns GP27, GP26, GP25, GP24, GP19, GP18; rows GP6, GP0, GP1, GP2, GP3,
with the thumbs on GP4). `v3` adds the `outlines` and `pcbs` sections that turn those points into an
actual board.

## PCB generation (v3)

`soffle-choc-version-v3.yaml` emits a `kicad8` PCB with a 5 mm filleted hull outline built from
22 x 21 mm rectangles around each key, and these [ceoloide](https://github.com/ceoloide/ergogen-footprints)
footprints:

- `switch_choc_v1_v2`, hotswap, front-mounted
- `diode_tht_sod123`, SMD only, on the back
- `led_sk6812mini-e`, reverse-mounted on the back so it shines up through the board
- `rotary_encoder_ec11_ec12` x2 per half, on the two `extra` points (A/B on GP23/GP22 and GP7/GP8)

Everything is single-sided (`reversible: false`), so the two halves are separate board files rather
than one flippable design.

Build it with:

```bash
npx ergogen soffle-choc-version-v3.yaml --output output
```

## Controller

`sofle-choc-pro.kicad_sch` is a self-contained RP2040 controller rather than a socketed
microcontroller module:

- RP2040 with a 12 MHz crystal and 16 MByte SPI flash
- AP2112K-3.3 LDO, 3.3 V and 5 V rails, polyfuse on VBUS
- USB Type-C (16 pin) with SRV05-4A ESD protection
- BOOT push switch

Symbols come from the JLCPCB plugin libraries (`PCM_JLCPCB-*`), so the design is aimed at JLCPCB
assembly. The `.kicad_pcb` file is still empty: no layout has been done yet.

## Requirements

- [Ergogen](https://github.com/ergogen/ergogen) with the ceoloide footprint library available
- KiCad 8
- The JLCPCB symbol/footprint libraries, installed via the KiCad Plugin and Content Manager
